# FiveM Docs corrections

Public corrections for [FiveM Docs](https://fivemdocs.com), an independent community reference maintained by Livvux. This repository contains no application source code.

[Report a documentation correction](https://github.com/Livvux/fivemdocs-feedback/issues/new?template=correction.yml). A GitHub account is required. Reports are public: never include license keys, tokens, player identifiers, private server addresses or unredacted logs.

Include the article URL, incorrect statement, expected correction, primary source or minimal reproduction, and relevant artifact/runtime versions. Website tests and source review do not certify behavior inside FiveM.

For an error in the official Cfx.re documentation, use [the official contribution workflow](https://github.com/citizenfx/fivem-docs).
